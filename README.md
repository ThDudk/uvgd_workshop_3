This project is a Godot workshop created for the University of Victoria's Game Development Club. The goal is to teach the following concepts:
- Simplex & Fractal noise
- Blue noise & Scatter Systems
- How to implement multithreading to improve performance.

# Downloading

Begin by [cloning this repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository). This can be done in github by pressing `code` then `Download ZIP`.

<img width="1649" height="993" alt="Screenshot 2026-11-03 at 1 50 38 PM" src="https://github.com/user-attachments/assets/0d9f1c2d-21c2-4a90-96bf-f4d0a14e8387" />

Alternatively, you can use the terminal:

```bash
git clone https://github.com/ThDudk/uvgd_workshop_3.git
```

Once the project is installed, simply open it in Godot and start playing around!
